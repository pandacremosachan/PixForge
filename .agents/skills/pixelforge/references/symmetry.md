# 对称范围与变换

对称是指定范围中的结构关系。先确定“哪些像素或部件、围绕哪条轴线或哪个中心、经过什么变换相互对应”，再选择绘制和检查方法；不默认整张贴图左右对称。

## 范围与对象

| 范围 | 如何确定约束 |
|---|---|
| 整张图 | 只有设计要求整个资源遵循同一变换时，才检查全画布。 |
| 局部部件 | 芯片、端盖、扳手头、接头、边框可各有自己的轴线和中心；一个部件通过不代表其他部件或整图通过。 |
| 部件之间 | 两个部件可通过镜像、旋转或平移对应；要核对相对位置、朝向与语义，不能仅检查各自外框。 |
| 结构层或掩膜 | 遮挡、背景装饰和定向光照会干扰成品颜色检查；必要时单独导出目标结构或语义掩膜。 |

例如卡片主体局部左右对称，接口绕另一条偏移轴线对称，斜放工具头沿自身斜轴对称，而整个构图可以不对称。绘制前用部件名、边界/掩膜、轴线/中心和变换简要记录各自规则。区域必须包含该部件的完整对应关系，不能靠裁掉不匹配的部分制造通过。

## 变换分别判断

- **水平或竖直轴镜像**：轴线可以经过整图中心，也可以位于某个局部部件的中心。对宽 `W`、高 `H` 的局部画布，镜像坐标为 `x'=W-1-x` 或 `y'=H-1-y`；偶数尺寸的轴线位于两个像素中心之间。
- **斜轴镜像**：按部件实际轴线判断。正方形局部画布的两条对角线是 `x=y` 和 `x+y=W-1`，不能以画布左右镜像替代。偏移或斜放部件的轴线未必穿过整张图中心。
- **中心对称**：绕指定中心转 180° 后对应，可用于长方形部件；不要求水平或竖直镜像。
- **旋转对称**：绕指定中心转 90°、180°或设计选定的角度后对应。风扇、旋纹等可以旋转对称而没有镜像对称。检查器的 `rotate90` 只要求 90°旋转；`d4` 同时要求 90°旋转与两个正交镜像，两者不能混用。
- **重复与部件对应**：平移重复可以组织触点、齿列与拼接段，但不必具有镜像轴。无缝平铺也不是对称性的充分条件，按实际排列和接缝另行检查。

任意角度的斜轴或旋转一般不能让所有像素中心严格落回原网格。此时先核对轮廓、距离、宽度及部件位置等设计关系，说明是否采用像素栅格近似；不能用插值、模糊或强行折叠像素掩盖误差。现有检查器只做下述网格精确变换，不宣称支持任意角度。

## 局部检查与坐标

`pixelforge preview PNG --region X Y W H` 先裁取指定区域，再按该区域的坐标执行对称检查；图片仍保持只读。镜像轴在源图中的位置为 `x=X+(W-1)/2` 或 `y=Y+(H-1)/2`，旋转中心是这两个坐标的交点。裁片可以位于源图任意合法位置，轴线不需要等于源图中线。

正方形裁片的主对角线对应源图的 `y-x=Y-X`，反对角线对应 `x+y=X+Y+W-1`。对角线、90°旋转和 `d4` 要求被检查区域为正方形；180°旋转允许长方形。

例如下列坐标只是演示，实际范围应从目标部件和 UV 确定：

```powershell
# 局部部件关于源图 x=5.5 对称，不要求整图左右对称。
python <skill-base-dir>/scripts/pixforge_client.py preview asset.png --region 2 4 8 6 --symmetry lr

# 偏移的局部斜轴：源图 y-x=-2，检查 6×6 部件。
python <skill-base-dir>/scripts/pixforge_client.py preview asset.png --region 5 3 6 6 --symmetry diagonal

# 另一个局部部件只要求中心对称。
python <skill-base-dir>/scripts/pixforge_client.py preview asset.png --region 2 4 8 6 --symmetry rotate180
```

不同部件分别运行各自约束；动画先分帧，再在每帧内采用这些区域。非矩形目标、互相遮挡的部件或内部结构不能仅靠矩形裁片区分时，导出独立结构层/语义掩膜后检查。`--symmetry-space alpha` 严格比较透明度数值；`silhouette` 只比较 `alpha > --alpha-cutoff` 的可见轮廓，默认阈值为 0。两者都不证明内部槽位、触点或芯片布局；最终 RGBA 对称使用默认 `rgba`。阈值须按目标用途选择，不把辅助阈值当作渲染器的实际 cutout 规则。

`mirror on` 的轴线固定为当前画布竖直中线，图层也不会改变它。局部镜像可先在独立部件画布中构造，再按目标位置组合；斜线、旋转和成对部件使用对应母版或坐标变换，完成后检查最终 PNG。对称约束只应用于设计选定的部分，颜色、高光与磨损是否对应须另行确定。

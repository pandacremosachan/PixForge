# LabPBR data maps through the public application

Read this for normal/AO/height, smoothness/F0/metal, porosity/SSS or emission work. Discover `minecraft-material/v1`; the skill remains an API-v1 standard-library client. Software 2.7 owns map storage, editing, shader contracts and export. Do not implement those inside the skill or edit project/checkpoint JSON directly.

Use `session minecraft-material` / MCP `inspect_minecraft_material` for the current raw planes, pixel values, histograms, decoded meanings and target issues. `--resource namespace:path` resolves source `_n`/`_s` with the software's priority and provenance. Inspecting is read only. In the native desktop use 资源 → Minecraft 数据材质; the default tool only inspects.

Read the current project with `status`, then configure with `session minecraft-material-configure --settings @settings.json`. Example settings: `{"profile":"labpbr-1.3"}`. Use `minecraft-material-import --role normal|specular --path FILE` for exact-size 8-bit PNG, or add `--channel r|g|b|a` to copy the mask's R plane into one channel. Use `minecraft-material-edit --role ROLE --channel CHANNEL --operations @operations.json` for atomic batches such as `[{"rect":[2,3,1,1],"value":0}]`. Submit current document/revision tokens on every write. The MCP equivalents are `configure_minecraft_material`, `import_minecraft_material`, `edit_minecraft_material`.

Data alpha is not opacity. Normal A is height; specular A 0..254 is emission and **255 means ignored/zero**, not maximum emission. Normal RG encodes DirectX XY with reconstructed Z; B is AO. Specular R is perceptual smoothness; G switches between F0, named/reserved metal IDs and albedo-metal fallback; B switches between porosity and SSS. View all eight planes and the software's decoded report. Never route a data map through color-layer compositing, sRGB correction, resizing or ordinary paint operations.

Bind the consuming project's actual shader name/version, loader/version, required options and true/false/null feature declarations. Supply an authorized local ZIP/directory and expected SHA when available. Treat unknown as unknown. The bundled owned Probe 1.0.0 example pins OptiFine I6 / Forge 47.2.18 and explicitly excludes height/POM, named metals, porosity and SSS. Do not generalize that loader combination to other Forge builds or install it automatically. Shader source inspection, offline GPU decoding and a declaration do not establish game behavior.

Use normal `minecraft-check`, inspect all eight data planes and retain real user consent for the currently shown content before guarded Minecraft export. The software pairs data sidecars with the same albedo binding, frame layout and animation indices. Cross-frame category interpolation, impossible normals, unsupported used features, source hash changes and conflicting global LabPBR declarations can block export. Save editable drafts while resolving these issues. A content or dependency change requires a fresh check; no separate workflow review receipt is used.

Data projects and recovery history require software 2.7 format v4. Preserve ordinary project/history compatibility when upgrading. Game comparison with data maps requires observed active shader/hash/options/reload context from the opt-in Forge fixture; report offline and actual game validation separately. For exact byte semantics and supported target boundaries use the installed application's `MINECRAFT_MATERIAL_DATA.md` and returned capability/report data.

# Forge 1.20.1 资源管线示例

这是软件自带的合成测试方块，使用原创 16×16 像素和简单模型；不包含用户作品或 Minecraft 原版素材。工程尚未批准正式导出。

打开 `target-demo.pixforge` 后选择“资源 → Minecraft 目标、资源与检查…”，查看保存的 Forge 1.20.1 配置、当前画布绑定和资源检查结果。来源为空，因此无需本机路径或外部依赖。修改配置可撤销，取消草稿不改变工程。

“确认并导出 Forge 1.20.1 资源包…”会生成格式 15 的 pack.mcmeta、纹理、模型、方块状态和旧版 models/item 引用。该示例描述 `pixforge_demo:resource_demo` 的外观，须有模组注册对应方块才会出现在游戏中；软件不会注册方块、安装资源包或启动游戏。已有复杂状态的模组应选择“仅替换纹理”，并提供其实际资源入口和依赖。

`target.json` 是可通过公开 minecraft-configure 接口应用的同一配置。此工程使用 v2 元数据，需要 PixForge 2.3+；旧软件会明确拒绝，避免保存时丢失目标配置。

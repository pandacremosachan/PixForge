# 设计与视觉验收

先看用户参考和项目相邻素材，确定像素密度、主体比例、颜色角色、光源与材料处理。新设计先完成一个代表样，在原尺寸确认大形后再扩展细节或整套。

## 绘制与自查

- **形体**：主体、负形、间距和方向在实际尺寸下可读；修正相切、突刺、断线和被高光切碎的轮廓。
- **主次**：主体、结构阴影、高光和类别标记强弱清楚。边框与装饰不抢主体；过近色阶没有作用时合并。
- **材料**：用面结构、连续反射、裂缝或颗粒表现目标材料。细节服从结构，避免用随机亮点填空。
- **像素组织**：先形成有意义的色簇，再补单像素细节。孤立像素、抖动和抗锯齿按参考用途判断，不设通用数量标准。
- **成套一致**：保持结构尺度、光源、基线及已有类别色；用必要的部件或颜色变化区分功能与等级。

局部修改保留已认可区域，以原生 RGBA 为基底。保护范围可用 `asset inspect` 的 `options` 的 preserve_mask/compare 检查，精确配色可用 palette 数组；导入与透明覆盖见 [操作约定](operations.md#png-与剪贴板)。

## 按用途查看

| 用途 | 必看内容 |
|---|---|
| 通用 | 原尺寸、最近邻放大、实际绘制尺寸 |
| 透明图标 | 深浅背景下的轮廓、毛边与半透明边缘 |
| 平铺材质 | 实际使用面裁片的 3×3，重复大斑和接缝 |
| 模型 | 真实 UV、方向/状态、受影响面、缩小后的串色 |
| 动画 | 全部源帧及真实顺序/时长，循环、方向与基线 |
| GUI | 实际控件尺寸及所需状态、字体/图标基线 |

看图后先修正已经发现的问题，再展示给用户评议。原尺寸杂乱时简化结构/色簇；材料难辨时改面与高光；类别难分时核对颜色角色和部件；动画跳动时查帧位置与时序。修改后重看受影响结果。

统计只验证声明的约束；视觉结论来自实际图像和用户偏好。按本次任务保留必要对照即可，简单图不另写验收报告。

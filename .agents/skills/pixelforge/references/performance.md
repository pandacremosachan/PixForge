# 迭代效率

EXE 直接处理命令参数与帮助，工程操作复用同一 workspace/runtime 的进程。首次工程操作可能包含初始化时间，后续命令沿用该进程；正常迭代保持工程可用，不在每次调用后关闭或重新启动。

- 首次使用当前程序版本时查询 `project info`；参数不熟悉时只查对应子命令的帮助，复用已有说明。
- 将相关笔画合为一个 `canvas draw` 原子批次，复用响应 state 继续操作；需要传递给下一条命令时保存操作响应，不额外查询同一状态。
- 每个主要阶段同步或展示一次。`workbench present` 已包含同步与截图，展示前无需紧接着再调用 `workbench wait`。
- 草稿轮次检查当前改动，交付前检查全部受影响成员、帧和状态；内容与来源未变时复用有效检查结果。
- 长动画可降低讨论预览倍率或背景数量，或使用真实 HTML 播放器，保留原生像素和所有需检查的帧。
- 精确色簇、平铺、保护蒙版按任务启用；保护蒙版始终检查完整源图。
- 用 `asset inspect --report-path` 或 `asset playback --report-path` 保存完整报告，先读失败项；通过返回的文件路径看图，不在对话展开逐像素或 base64 数据。

共享窗口任务继续使用当前工程；用户明确选择独立批处理时见 [离线事务](transactions-review.md)。
